# ADR-0003: Адаптер джерела банківських даних (банківський API та CSV)

- Status: Accepted
- Date: 2026-11-11

## Context

FinWise має працювати як реальна система й отримувати операції з банку за згодою користувача. Під час навчання доступу до реальних рахунків немає, тому потрібне інше джерело даних, наприклад CSV-виписка.

## Considered Options

1. Лише CSV (прототип).
2. Вшити роботу з банківським API прямо в логіку.
3. Зробити інтерфейс «джерело операцій» з кількома реалізаціями.

## Decision

Обрано інтерфейс «джерело операцій» з двома реалізаціями: банківський API (для реальної роботи) і CSV-імпорт (для навчання й тестів). Яку з них використовувати, задається змінною оточення.

## Consequences

- Решта системи (категоризація, ліміти, прогноз) не залежить від джерела даних і однаково тестується на CSV.
- Джерело можна змінити без зміни коду.
- Мінус: реалізацію для реального банку доведеться писати окремо, і для неї знадобиться авторизація та виконання вимог банку.
