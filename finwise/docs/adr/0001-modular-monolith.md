# ADR-0001: Модульний моноліт із окремим фоновим воркером замість мікросервісів

- Status: Accepted
- Date: 2026-11-11

## Context

Проєкт розробляє одна людина, тому система не повинна бути надто складною. Водночас FinWise потрібні фонові завдання: отримання операцій з банку, їх категоризація, перевірка лімітів і сповіщення. Вони не повинні сповільнювати відповіді користувачам.

## Considered Options

1. Мікросервіси.
2. Один процес для всієї логіки.
3. Модульний моноліт з окремим воркером.

## Decision

Обрано модульний моноліт. API обробляє запити користувачів, а окремий контейнер-воркер із тієї ж кодової бази виконує фонові завдання. Код поділено на модулі: витрати, категоризація, ліміти, сповіщення, прогноз.

## Consequences

- Так простіше розробляти й тестувати, а проблеми з банком не впливають на швидкість API.
- Воркер можна масштабувати окремо.
- Мінус: у розгортанні два процеси замість одного, і їх треба моніторити окремо.
- Якщо буде потрібно, модулі можна винести в окремі сервіси.
