# ADR-0002: PostgreSQL як основна база даних

- Status: Accepted
- Date: 2026-11-11

## Context

Дані FinWise добре лягають у таблиці: операції, категорії, ліміти. Для фінансових даних важливо, щоб зміни виконувалися цілісно.

## Considered Options

1. PostgreSQL.
2. MongoDB.
3. SQLite.

## Decision

Обрано PostgreSQL, яка запускається в окремому контейнері.

## Consequences

- Надійні транзакції, легко запускати в Docker, багато інструментів для тестів і резервних копій.
- Мінус: потрібно налаштувати сховище для даних і закрити доступ до бази ззовні, щоб її бачив лише застосунок.
